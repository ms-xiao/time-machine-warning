One line, at most 120 characters: the funniest warning label for a time
machine. A judge model compares entries pairwise against the published
judge brief and picks the funnier line.

**The line** (102 characters):

> WARNING: Never shake hands with yourself. The warranty covers one of you, and it picked the other one.

The joke turns a real hazard of time travel — meeting (and touching) your
own past self — into the punchline, saved for the last few words, and keeps
the straight face of a genuine safety notice.

`main.ts` (Node 22, standard library only) prints the line and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the line exactly as submitted.
